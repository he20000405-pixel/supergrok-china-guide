# Grok Imagine Video 1.5 怎么用？图片生成视频、提示词与失败排查

**直接答案：**打开 [grok.com/imagine](https://grok.com/imagine)，或在当前版本的 Grok iOS、Android 应用中进入 Imagine。准备一张自己有权使用的图片，说明主体怎样运动、镜头怎样移动以及需要什么声音，然后生成并逐项检查画面、动作和音频。

xAI 于 **2026 年 6 月 16 日**发布 Grok Imagine Video 1.5，并把 Video 1.5 Fast 推向 Grok 网页和移动应用。官方同时宣布 Projects、多任务并行和素材搜索功能；这些功能可能按账号和平台逐步出现，实际入口以当前页面为准。

**English summary:** Grok Imagine Video 1.5 turns a starting image into a short video with motion and generated audio. This guide covers the consumer workflow on grok.com and the Grok apps, not the separately billed xAI API.

**关键词：**`Grok Imagine Video 1.5` · `Grok 图片生成视频` · `Grok Imagine 怎么用` · `Grok 视频提示词` · `SuperGrok Imagine`

## 先分清消费者 Imagine 和 API

xAI 的同一篇发布说明同时提到了 Grok 消费者产品和 Imagine API，但两者不是同一个购买入口。

| 对比项 | Grok 网页或 App 中的 Imagine | xAI Imagine API |
|---|---|---|
| 使用入口 | `grok.com/imagine`、Grok iOS 或 Android | xAI 开发者控制台和程序调用 |
| 面向对象 | 在网页或手机直接创作图片、视频的普通用户 | 把视频生成接入软件的开发者 |
| 计费关系 | 由当前 Grok 套餐和消费者用量规则决定 | 独立的 API 计费体系 |
| 本文范围 | 详细说明 | 不提供充值、价格或代码教程 |

购买 SuperGrok 会员不等于获得 API 额度。本文只说明 Grok 网页和 App 中的 Imagine 使用方式。

## 开始前先完成五项检查

### 1. 使用正确网址和账号

网页端打开 [grok.com/imagine](https://grok.com/imagine)。xAI Consumer FAQ 建议使用 `grok.com`，部分旧地址或第三方入口可能缺少 Projects 等功能。

进入后先确认当前登录的是准备使用 Imagine 的账号。如果过去分别使用 Apple、Google、X 或邮箱登录，可能已经创建了不同的 xAI 账号；生成记录、订阅权益和周用量不会自动合并到另一个账号。

### 2. 分别检查订阅状态和周用量

先回到最初付款的平台确认订阅状态。网页订阅可打开 Grok 的 `Settings → Billing`；Apple 或 Google Play 订阅应在原商店账号的订阅列表中核对。确认订阅仍然有效后，再打开 `Settings → Usage`，记录以下信息：

- 周用量已经使用多少；
- Imagine 占用了多少用量；
- 页面显示的重置日期和时间；
- Extra Usage Credits 是否还有余额。

xAI Consumer FAQ 说明，付费用户采用共享周用量池。Chat、Imagine、Voice 和 Build 等产品会共同消耗这组用量；不同操作按计算资源消耗不同，生成高质量视频通常比普通聊天消耗更多。

### 3. 准备一张适合做视频的图片

第一次测试建议使用一张主体明确、背景不过度复杂的图片。可以在 Imagine 中先生成图片，也可以按当前页面提供的上传入口选择自己有权使用的图片。

xAI FAQ 对图片上传的一般建议是：需要处理画面细节时，优先使用高分辨率图片。FAQ 列出的常见格式包括 JPEG、PNG、WebP、HEIC 和 BMP。若 Imagine 无法读取图片，先转成 JPG 或 PNG，再重新选择一次。

### 4. 先决定视频只完成一个动作

短视频时间有限。第一次不要同时要求人物走路、转身、说话、变装和切换多个场景。先选一个可以清楚验收的动作，例如：

- 镜头缓慢推近；
- 人物转头看向窗外；
- 咖啡杯上方的蒸汽轻微飘动；
- 产品在桌面上缓慢旋转；
- 树叶随风摆动，背景保持稳定。

### 5. 确认图片可以安全上传

不要上传没有授权的私人照片、身份证件、订单信息、客户资料或包含密码、验证码、恢复码、API 密钥、session、完整 User ID 的截图。生成结果可能进入素材库或项目，上传前应先完成脱敏。

## 第一步：进入 Imagine 并选定起始图片

1. 网页打开 [grok.com/imagine](https://grok.com/imagine)，手机打开当前版本的 Grok App。
2. 确认页面显示的是准备使用的账号。
3. 进入 Imagine 后，从素材库选择一张已有图片，或使用页面当前提供的上传入口添加图片。
4. 选择图片后，确认预览中的主体、方向和裁切范围正确。

**预期结果：**页面已经选定一张起始图片，并出现用于描述动作或创建视频的输入区域。

**如果没有 Imagine 入口：**先确认使用的是 `grok.com` 而不是旧地址，再更新手机应用并重新登录一次。仍无入口时，检查套餐和 Usage；不要因为入口暂时没有出现而连续购买其他套餐。

## 第二步：按四个部分写视频提示词

一条容易执行的视频提示词，应依次说明：

1. **主体动作：**谁或什么在动；
2. **镜头运动：**镜头保持固定、推近、拉远还是横移；
3. **保持不变的内容：**人物外观、产品文字、背景构图等；
4. **声音要求：**环境声、音效、对白，或明确不要对白。

例如：

> 镜头缓慢推近桌上的咖啡杯，蒸汽向右上方轻轻飘动，窗外雨滴沿玻璃下滑。保持杯身图案和桌面构图不变。加入轻微雨声和室内环境声，不要对白。

这条指令只包含一个主要动作，并明确了镜头、画面保持项和声音。相比“让图片动起来并变得很电影感”，它更容易检查哪里符合要求、哪里需要修改。

## 第三步：提交生成并等待当前任务完成

1. 检查起始图片和提示词是否对应。
2. 点击输入区域旁的“生成”或“创建视频”按钮；按钮名称可能随网页和 App 版本调整。
3. 保持页面打开，等待该任务出现完成、失败或需要修改的状态。
4. 一项任务没有结果前，不要快速重复提交相同内容。

xAI 官方发布页给出的 Video 1.5 Fast 数据是：大约 **25 秒**生成一段 **6 秒、720p** 视频。这个数据用于说明官方版本的速度提升，不代表每个账号、每次生成都能在相同时间完成。

**停止条件：**任务长时间没有变化时，先记录发生时间和当前状态，再查看 [xAI Status](https://status.x.ai)。刷新一次仍无变化，就停止连续重试，避免消耗更多周用量。

## 第四步：按固定顺序验收视频

生成完成后，不要只看“能不能播放”。按下面顺序检查：

1. **主体是否保持一致：**人物、产品和文字是否发生明显变形；
2. **动作是否正确：**动作方向、速度和范围是否符合提示词；
3. **镜头是否正确：**是否真的推近、横移或保持固定；
4. **物理效果是否自然：**重量、碰撞、液体和背景运动是否合理；
5. **声音是否对应画面：**环境声、音效和对白是否在正确时间出现；
6. **清晰度是否符合当前套餐：**选择 720p 后是否回退到 480p；
7. **水印是否完整：**不要删除或遮挡 Grok 水印和来源标识。

xAI 把更连贯的动作、物理效果以及同一轮生成的音效、环境声和对白列为 Video 1.5 的改进方向。这些是官方产品说明，不是每段视频都达到同一质量的保证。

## 第五步：一次只改一个问题

如果结果不符合要求，先判断最主要的问题，再只修改对应部分：

| 问题 | 修改方式 | 暂时不要改什么 |
|---|---|---|
| 动作方向错误 | 把方向写成明确的左、右、前、后或顺时针 | 不同时更换主体和场景 |
| 镜头移动过大 | 改成“镜头固定”或“轻微推近” | 不增加第二个镜头动作 |
| 主体外观变化 | 补充“保持人物外观、服装和构图不变” | 不同时加入变装要求 |
| 背景过于混乱 | 要求背景保持稳定，只让主体运动 | 不增加多名人物和复杂粒子 |
| 音效不合适 | 单独说明环境声、音效或不要对白 | 不重写整段画面描述 |
| 对白不同步 | 缩短对白，只保留一句短句 | 不在同一段加入多人对话 |

每次修改后重新执行第四步验收。这样即使结果仍不理想，也能判断是哪条修改产生了影响。

## 第六步：用 Projects、并行任务和搜索管理素材

xAI 在 Video 1.5 发布时宣布了三项消费者工作流功能：

### Projects

把同一主题的起始图片、提示词和生成结果放入一个 Project。建立项目时使用可识别的名称，例如“咖啡产品短片”，不要使用“测试 1”“新项目”等无法区分的名称。

### Multiple agents

官方说明可以并行启动多个任务。并行生成适合比较不同镜头或动作，但每项任务都会占用计算资源。第一次使用时先并行两项，不要一次提交大量近似任务。

### Search

素材增多后，可以通过搜索查找已经生成的图片或视频。项目名称和提示词中保留清晰的主体词，例如“咖啡杯”“雨天窗边”“缓慢推近”，以后更容易检索。

这些功能若尚未出现在当前账号，不代表 Video 1.5 一定不可用。xAI 的发布说明采用“逐步推出”表述，应以网页和应用当前界面为准。

## 常见失败按这个顺序排查

| 现象 | 先检查 | 下一步 | 什么时候停止 |
|---|---|---|---|
| 没有 Imagine 或视频入口 | 是否打开 `grok.com`、账号是否正确、App 是否为当前版本 | 重新登录一次并检查套餐、Usage | 仍无入口时联系 xAI，不重复购买 |
| 图片无法上传 | 文件是否为常见图片格式、是否过大或损坏 | 转成 JPG/PNG，换一张无敏感信息的图片测试 | 两张正常图片都失败时停止重复上传 |
| 任务排队后失败 | 保存提示词、发生时间和错误文字 | 查看 xAI Status，简化为一个动作后再试一次 | 再次失败时联系 xAI 支持 |
| 请求 720p，结果变成 480p | 确认订阅状态并查看 `Settings → Usage` | xAI FAQ 将这种回退解释为当前套餐的 720p 上限已用完 | 不要把清晰度回退直接判断为订阅失效 |
| 付费计划有效但不能继续生成 | 检查共享周用量是否已满 | 按页面显示的重置时间或官方选项处理 | 已满时不要通过重复购买判断账号问题 |
| 页面显示 Free | 核对原购买账号和当前登录方式 | 进入付款后仍显示 Free 专题 | 已有扣款或待处理交易时不要再次购买 |
| 提示词被内容安全系统拦截 | 删除可能涉及禁止内容的要求 | 改成符合规则的普通创作内容 | 不尝试绕过安全限制 |
| 生成结果带水印 | 无需排查，这是官方设计 | 保留水印和来源标识 | 不使用工具删除、遮挡或修改水印 |

如果计划仍有效但共享周用量已经用完，请使用 [SuperGrok 周额度与订阅状态排查]({{ '/guides/supergrok-weekly-limit-vs-subscription/' | relative_url }})。如果已有最终扣款但账号仍显示 Free，请进入 [SuperGrok 付款后仍显示 Free 指南]({{ '/guides/supergrok-paid-but-still-free/' | relative_url }})。

## 套餐与购买边界

xAI 套餐页把图片和视频生成列为 Grok 的消费者能力，并说明付费计划会提高各项产品的使用上限。官方 Video 1.5 发布页没有把网页和 App 的消费者入口统一限定为单一套餐，因此不要仅根据第三方文章判断自己必须购买哪一档。

先在当前账号检查 Imagine 入口，并回到最初付款的平台核对订阅状态，再查看 `Settings → Usage`。只有在账号**没有有效订阅、没有待处理交易，也没有已经完成的扣款**时，才可以前往 [ChongGrok SuperGrok 页面](https://chonggrok.com/supergrok?utm_source=github_guides&utm_medium=referral&utm_campaign=grok_imagine_video)查看实时方案，并在付款前向客服确认当前方案能否满足所需的 Imagine 用量和清晰度。

已有有效订阅、待处理交易或扣款记录时，应先处理原账号的用量或权益问题，不要再次购买。

## 隐私、版权与内容安全

- 只上传自己创作、获得授权或依法可以使用的图片。
- 上传真人照片前，应获得相关人员许可；不要把他人的私密照片用于生成内容。
- 不上传身份证件、银行卡、订单记录、公司内部资料或包含登录凭证的截图。
- 不尝试绕过 Grok 的内容安全限制。订阅付费不代表可以关闭审核规则。
- 生成内容应保留 Grok 水印和其他来源标识，并在公开发布前再次检查画面、声音和潜在误导风险。
- ChongGrok 与 xAI、X 不存在隶属、授权或官方合作关系。Imagine 的入口、用量和清晰度可能调整，以 xAI 实时页面为准。
